# Voces de Tocopilla

Pasos para subirla a Vercel:

1. Sube esta carpeta a un repositorio de GitHub, o arrastra la carpeta completa a vercel.com/new.
2. En Vercel entra a Storage, crea una base Upstash Redis gratis y conéctala a este proyecto.
3. En Settings, Environment Variables, agrega EDIT_KEY con la clave que quieras darle al equipo.
4. Haz Redeploy. Listo.

Quien tenga la clave puede escribir. Quien no, solo lee.
